# 📚 LLM & Agent 技术笔记仓库

欢迎来到我的技术知识库！这里汇总了我在 **LLM/Agent 相关领域**的学习笔记、实践文档和资源整理，包含对前沿范式与开源项目的深度梳理。

---

## 📂 仓库目录说明

| 目录/文档 | 核心内容简介 |
| :--- | :--- |
| **`Harness Engineering`** | Agent 系统的「 harness 工程思想」笔记，讲解如何构建稳定、可扩展的 Agent 运行时与调度基础设施，让复杂多智能体任务可管理、可观测、可迭代。 |
| **`Superpowers`** | Agent 超能力（扩展能力）相关资料，包括工具调用、记忆系统、插件生态、沙箱执行等增强 Agent 能力的关键模块实践与原理。 |
| **`DeerFlow`** | 字节跳动开源的 SuperAgent 框架 DeerFlow 深度学习笔记，包含架构解析、使用指南、二次开发思路与实践经验。 |
| **`LLM Wiki`** | Andrej Karpathy 提出的 LLM Wiki 范式的完整学习与实践笔记，探索如何用 LLM 构建「一次编译、永久复用」的结构化个人知识库，替代传统 RAG 的痛点。 |

## ✨ 仓库特点

- **内容体系化**：从底层思想（Harness Engineering）、能力扩展（Superpowers）到具体项目（DeerFlow）与新范式（LLM Wiki），形成完整的 Agent 学习路径。
- **实践导向**：所有笔记均结合理论与落地场景，包含概念解析、核心流程、关键问题与优化思路，可直接作为学习与开发参考。
- **持续更新**：随着对 Agent/LLM 领域的学习与实践，会不断补充新的笔记、案例与踩坑经验。
